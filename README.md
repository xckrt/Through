# Сквозь

**Русский** · [English](README.en.md) · [Сайт](https://xckrt.github.io/Through/)

Программа для Windows, которая обходит блокировки провайдера — YouTube, Discord вместе с голосом, Telegram,
игры, сайты — и делает это сама. Проверяет, что именно режут, подбирает рабочую стратегию и дальше держит
обход без вашего участия: после перезагрузки, при смене Wi-Fi, когда провайдер меняет фильтр. Одна кнопка.

![Обзор Сквозь](site/img/overview-dark.png)

## Установка

Скачайте **Through-Setup-x.y.z.exe** со страницы [релизов](https://github.com/xckrt/Through/releases/latest)
и запустите. Один раз появится запрос администратора — Сквозь ставит службу, которая и держит обход. .NET
ставить не нужно, удаляется как обычная программа.

Через пакетные менеджеры: `winget install xckrt.Through`, либо Scoop —
`scoop bucket add through https://github.com/xckrt/Through` и `scoop install through`.

Не хотите ставить — **Through-Portable-x.y.z.zip**: распакуйте и запустите `Through.exe`. Обход живёт, пока
открыто окно; данные лежат в папке `data` рядом.

## Как это работает

Сквозь прогоняет каждый сервис по этапам — DNS → TCP → TLS → HTTP → передача — и по тому, где рвётся,
понимает способ блокировки: RST по имени сайта, тихий дроп, «заморозка на 16 КБ», подмена DNS. Под этот
диагноз она перебирает стратегии [zapret](https://github.com/bol-van/zapret), от простых к сложным, и
оставляет ту, что прошла проверку целиком. Служба следит дальше и переподбирает сама, если что-то перестало
работать.

Кроме сайтов умеет:

- **Telegram** — встроенный прокси (порт [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy), без Python):
  трафик уходит через веб-версию Telegram, а если её режут — через Cloudflare. Прокси прописывается в клиент сам.
- **Голос Discord** — проверяется честно, UDP-пакетом на голосовые серверы; не проходит — подбирается
  голосовой профиль.
- **Защищённый DNS** — запросы системы через DNS-over-HTTPS (Cloudflare, Google, Quad9). Если DoH замолчит,
  прежний DNS вернётся сам, без обрыва.
- **Свои приложения и игры** — нажмите «Выбрать запущенную программу», поиграйте полминуты, и домены с портами
  соберутся сами. Есть и заготовки: Dead by Daylight, Roblox, Twitch.
- **Профили сетей** — дома и на мобильном интернете стратегии могут быть разными; Сквозь узнаёт сеть и ставит нужную.
- **«Почему не открывается?»** — вставьте адрес сайта, и Сквозь скажет, кто виноват: провайдер, адрес, DNS или
  сам сайт.
- **Android** — прокси Telegram на телефоне (и по Wi-Fi, и по мобильному) плюс проверка сети. Сборка — в
  [docs/android.md](docs/android.md).

Ещё есть тёмная тема, значок в трее с переключателями, замер скорости YouTube до и после обхода, автообновление
zapret и самой Сквозь со сверкой SHA-256. И общая база стратегий: по желанию можно поделиться тем, что помогло
у вашего провайдера, — тогда следующим подбор займёт секунды.

## Что уходит в сеть

Сквозь ничего не шлёт без спроса. Обращается она только сюда:

| Куда | Зачем | Что уходит |
| --- | --- | --- |
| github.com (bol-van/zapret, xckrt/Through, Flowseal) | скачать zapret, проверить обновления, списки доменов Cloudflare для Telegram | обычный HTTPS-запрос |
| сайты из проверки (youtube.com, discord.com, …) | понять, что режут | то же, что браузер |
| 1.1.1.1, 8.8.8.8, 9.9.9.9 | защищённый DNS, если он включён | DNS-запросы внутри HTTPS |
| www.youtube.com, googlevideo.com | замер скорости YouTube по кнопке и при подборе | загрузка куска публичного ролика |
| общая база стратегий (Cloudflare Worker) | подсказки перед подбором | ничего, кроме самого запроса |
| общая база стратегий | **только если включено «Делиться итогами»** | id сервиса, id стратегии, «помогла или нет», версии Сквозь и zapret |

IP-адреса, адреса сайтов и идентификаторы в базу не попадают — провайдера сервер узнаёт по самому соединению.
Отчёты об ошибках не уходят сами: «Сообщить о проблеме» открывает черновик issue на GitHub, и весь текст виден
до отправки. Прокси Telegram слушает только этот компьютер, а переписку шифрует сам Telegram — Сквозь её не видит.

## Сборка

Нужен .NET 8 SDK.

```
dotnet build
dotnet run --project tests/Through.SelfTest                 # тесты, интернет не нужен
dotnet run --project src/Through.Tray                       # окно
dotnet run --project src/Through.Cli -- --only youtube      # проверка в консоли
dotnet run --project src/Through.Cli -- --telegram          # прокси Telegram: все DC
dotnet run --project src/Through.Cli -- --dns               # защищённый DNS
dotnet run --project src/Through.Cli -- --speed             # скорость YouTube
```

Установщик и переносную версию собирает `pwsh build/publish.ps1 -Version 1.2.0`; релиз — GitHub Actions по тегу
`v*`. Устройство проекта — в [docs/architecture.md](docs/architecture.md), общая база стратегий — в
[server/strategy-base](server/strategy-base).
