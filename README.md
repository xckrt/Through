# Tropa

Диагностика сетевой доступности сервисов и автоматическая настройка DPI-обработки для Windows.

Сейчас в репозитории ядро: **пробник**, который проверяет сервис по этапам
(DNS → TCP → TLS → HTTP → передача) и говорит не просто «не работает»,
а *как именно* сломано соединение: RST по SNI, молчаливый дроп, заморозка потока на ~16 КБ,
подмена DNS, замедление.

```
$ tropa-probe --only youtube,cloudflare
OK    ya.ru              HTTP 200                     180 мс
FAIL  youtube video      [Tls] TlsReset                45 мс
      RST во время рукопожатия: похоже на фильтр по SNI
FAIL  cf 64 KB           [Transfer] TransferStalled  4210 мс
      поток встал на 16.3 КБ: почерк «заморозки 16 КБ» (ТСПУ)
```

Код выхода 0, если всё доступно, 1 если нет. `--json` для машинного вывода.
Цели правятся в `targets.json` без пересборки.

При провале TLS пробник повторяет рукопожатие на тот же IP с нейтральным SNI и сообщает,
фильтруют ли соединение по имени сервиса или глушат весь адрес.

## Установка

Скачайте **Tropa-Setup-x.y.z.exe** со страницы [релизов](https://github.com/xckrt/Tropa/releases/latest)
и запустите. Windows один раз спросит разрешение администратора: Тропа ставит службу, которая держит
обход после перезагрузки. .NET ставить не нужно, всё внутри. Удаляется Тропа как обычная программа,
через «Приложения и возможности».

## Как пользоваться

Откройте Тропу. Проверка запускается сама. Если что-то режут, нажмите «Подобрать обход»: Тропа скачает
zapret из официального релиза, сверит SHA-256 архива и `winws.exe` с закреплёнными в `engine.json`,
переберёт стратегии и включит защиту. Дальше служба держит обход и сама подбирает заново, если провайдер
что-то поменял.

- **«Почему не открывается?»** — вставьте адрес любого сайта: Тропа скажет, кто виноват (провайдер, адрес,
  DNS или сам сайт) и, если это лечится, обойдёт его одной кнопкой.
- **Приложения** — добавьте игру или сайт, который работает плохо: есть заготовки (Dead by Daylight,
  Roblox, Twitch) или свой список доменов и игровых портов.
- **Обновления** — zapret обновляется сам (раз в сутки, со сверкой хешей и откатом), о новой версии Тропы
  окно скажет само и обновится по кнопке.
- **Проблемы** — «Настройки → Сообщить о проблеме» открывает черновик issue с версиями и журналами.
  Ничего не уходит без вашего нажатия. Если Тропа упала, при следующем запуске она предложит то же самое.

Для отладки то же есть в консоли: `tropa-probe --plan` и `--tune` (от администратора),
`Tropa.Service.exe install | uninstall | run`.

## Сборка

Нужен .NET 8 SDK.

```
dotnet build
dotnet run --project tests/Tropa.SelfTest
dotnet run --project src/Tropa.Cli -- --only youtube,discord
dotnet run --project src/Tropa.Tray      # окно: проверка запускается сама
```

Установщик: `pwsh build/publish.ps1 -Version 1.0.0` → `artifacts/Tropa-Setup-1.0.0.exe`.
Релиз собирает GitHub Actions по тегу `v*` (`.github/workflows/release.yml`).

Тесты поднимают локальный сервер, который изображает каждый способ блокировки,
и проверяют, что пробник его узнал. Интернет для них не нужен.
